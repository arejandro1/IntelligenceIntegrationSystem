# 里程碑实施流程

按已经批准的 Plan 执行，只执行批准任务。

要求：

1. 只实现当前里程碑。
2. 不扩大任务范围，不修改计划外文件。
3. 不进行无关重构。
4. 不复制 legacy 实现；新功能通过主仓库适配层、包装器和配置实现。
5. 不修改 Git 子模块。
6. 不调用未经批准的真实 API。
7. 不执行 git commit 或 git push。
8. 为新增业务逻辑增加测试。
9. 运行批准计划中列出的测试和验收命令。
10. 测试失败不得声称完成，如实报告失败。
11. 提交前确认工作区只包含批准范围内的修改。

最后输出：

- 修改文件；
- 实现内容；
- 执行命令；
- 测试结果（通过/失败/跳过）；
- 未通过项目；
- 已知限制；
- 建议提交信息。

## 实施后自检

- 仅批准文件发生变化；
- 无业务 Python 文件被意外修改；
- 无 requirements 变化（除非批准计划明确要求）；
- 无子模块变化；
- 未引入真实密钥；
- 未调用真实付费 API。
