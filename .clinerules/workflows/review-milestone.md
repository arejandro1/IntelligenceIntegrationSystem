# 里程碑代码复审流程

只审查当前未提交修改，默认不修改文件。

检查：

1. 是否超出批准范围（越界）；
2. 是否存在计划外重构（无关重构）；
3. 是否修改 Git 子模块；
4. 是否改变公共接口；
5. 是否引入不必要依赖；
6. 是否存在密钥泄露（日志、源码、配置）；
7. 是否缺少超时、重试、幂等、租约或日志；
8. 是否存在并发、资源或兼容风险；
9. 测试是否覆盖验收条件；
10. 测试是否被删除或跳过以凑通过；
11. 文档与代码是否一致；
12. 是否调用真实付费 API。

输出：

- 致命问题；
- 必须修复问题；
- 可后续处理问题；
- 测试缺口；
- 是否允许提交 Git。

约束：

- 不提出当前里程碑之外的新功能。
- 不修改任何文件（默认），只输出审查结论。
- 若发现致命问题，必须明确禁止提交。

## 复审范围

- 仅审查未提交的工作区修改（`git diff` 与未跟踪文件）。
- 核对修改文件清单与批准计划的允许文件清单是否一致。
