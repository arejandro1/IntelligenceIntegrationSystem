# 编码规则

## 最小修改

- 只实现当前批准里程碑要求的功能。
- 不进行无关重构。
- 不修改计划外文件。
- 不复制 legacy 实现；新功能应通过主仓库适配层、包装器和配置实现。

## 代码风格

- Python 新增代码必须使用类型标注（Type Hints）。
- 函数和类使用英文命名，遵循 PEP 8。
- 注释和日志使用简体中文。

## 配置与常量

- 不得硬编码模型名称、模型价格、峰谷时段、Guard 参数和密钥。
- 所有策略参数（时段、Guard、价格、政策版本、生效日期）必须配置化。
- 不在代码中保存真实密钥；密钥通过环境变量或本地配置文件注入。

## 网络请求

- 所有网络请求必须有超时设置。
- 必须使用有限重试，避免无限重试。
- 重试应带退避策略。
- 爬虫并发限制：普通爬虫并发为2，Playwright并发为1。

## 数据操作

- 数据操作必须考虑幂等：同一数据重复入队、重复处理不得产生副作用。
- 队列操作必须考虑并发安全。
- 处理中数据必须使用租约机制，超时自动释放。
- 同一队列项不得被两个worker同时认领。

## 子模块与适配

- 不直接修改 Git 子模块（AIClientCenter/、IntelligenceCrawler/、VectorDB/、MyPythonUtility/、PyLoggingBackend/）。
- 新增功能优先通过主仓库适配器、包装器和配置实现。
- 子模块接口变化时，优先在主仓库适配层兼容。

## 禁止项

- 禁止在业务代码中写死来源列表。
- 禁止在业务代码中写死峰谷时段、价格和政策日期。
- 禁止在日志中输出密钥、Token 和敏感字段。
- 禁止绕过规则预筛直接调用 AI API。
